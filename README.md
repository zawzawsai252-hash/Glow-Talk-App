# Glow-Talk-App
Glow Talk - chat and video call# GlowTalk - Short Video, Chat & Video Call App

**GlowTalk** သည် Short Video Sharing၊ Real-time Messaging (Chat) နှင့် High-Quality Voice/Video Calls များကို တစ်နေရာတည်းတွင် သုံးစွဲနိုင်ရန် ဖန်တီးထားသော Cross-Platform Mobile Application တစ်ခု ဖြစ်ပါသည်။

---

## 🌟 Key Features

* 📱 **Short Video Feed** - TikTok ကဲ့သို့ Vertical Video Scrolling၊ Like၊ Comment၊ Share၊ Duet နှင့် Stitch Features များ
* 💬 **Real-time Messaging** - Text၊ Voice Messages နှင့် Images များ အပြန်အလှန် ပေးပို့နိုင်ခြင်း
* 📞 **HD Voice & Video Calls** - 1-on-1 နှင့် Group Video Calling စနစ်များ
* 🔍 **Discover & Trending** - Trending Hashtags များ၊ Popular Users များနှင့် Videos များကို ရှာဖွေနိုင်ခြင်း
* 👤 **User Profiles** - မိမိ၏ Videos၊ Liked Content များနှင့် Profile ကို စိတ်ကြိုက် ပြင်ဆင်နိုင်ခြင်း

---

## 🛠️ Tech Stack & Architecture

* **Frontend:** Flutter / React Native
* **Backend:** Node.js (Express) / Go (Golang)
* **Database:** PostgreSQL / MongoDB & Redis (Caching)
* **Real-time & Media:** WebRTC, Agora SDK, Socket.io
* **Cloud Storage & Streaming:** AWS S3, Cloudinary, AWS Elemental MediaConvert
